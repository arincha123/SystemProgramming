Задание
Реализовать выполнение функции из библиотеки DLL в приложении.
1. Библиотека может быть реализована в среде Visual Studio.
2. Разработать приложение, вызывающее функцию из библиотеки, создается как консольное приложение C++.
3. Проект должен предусматривать обработку исключительных ситуаций (отсутствие файла библиотеки, отсутствие функции в библиотеке).
4. Разработать функцию расчета количества материала.
5. Оформить функцию как библиотечную, создать библиотеку.
6. Модифицировать функцию main программы для загрузки библиотеки, вызова библиотечных функций и выгрузки библиотеки.
7. Продемонстрировать работоспособность программы и перехват ею исключений.
8. Необходимо уведомлять пользователя о совершаемых им ошибках или
о запрещенных в рамках задания действиях.
9. Пример кода библиотеки (dllmain.cpp, testfunc.cpp) и программы (testdll.cpp) представлены во вложении.


Функция расчета количества материала.
С целью обеспечить одинаковый расчет количества материала,
требуемого для производства продукции, необходимо разработать функцию.
Функция должна принимать идентификатор типа продукции,
идентификатор типа материала, количество получаемой продукции – целые
числа, параметры продукции (два параметра) – вещественные,
положительные числа, а возвращать целое число – количество необходимого
материала с учетом возможного брака материала.
Функция должна рассчитывать целое количество материала,
необходимого для производства указанного количества продукции, учитывая
возможный брак материала. Количество необходимого материала на одну
единицу продукции рассчитывается как произведение параметров
продукции, умноженное на коэффициент типа продукции. Кроме того, нужно
учитывать процент брака материала в зависимости от его типа: с учетом
возможного брака материала необходимое количество материала должно
быть увеличено. Коэффициент типа продукции и процент брака –
вещественные числа.
Если в качестве параметров функции будут указаны несуществующие
типы продукции, материалов или другие неподходящие данные, то функция
должна вернуть -1.
